Operators

Operators are used to perform operations on values

Arithmetic Operators

+ → Addition

- → Subtraction

* → Multiplication

/ → Division

MOD → Remainder 


# Addition 
START
  PRINT "Enter first number:"
  INPUT a
  PRINT "Enter second number:"
  INPUT b
  SET result TO a + b
  PRINT "Result:" + result
END

# Subtraction
START 
  PRINT "Enter first number:"
  INPUT a
  PRINT "Enter second number:"
  INPUT b
  SET result TO a - b
  PRINT "Result: " + result
END

# Multiplication
START 
  PRINT "Enter first number:"
  INPUT a
  PRINT "Enter second number:"
  INPUT b
  SET result TO a * b
  PRINT "Result: " + result
END

# Division 
START 
  PRINT "Enter first number:"
  INPUT a
  PRINT "Enter second number:"
  INPUT b
  SET result TO a / b
  PRINT "Result:" + result
END

# Modulus 
START
  PRINT "Enter number:"
  INPUT a
  PRINT "Second number:"
  INPUT b
  SET result to a MOD b
  PRINT "Remainder:" + result
END

# Integer Divison
START
  PRINT "Enter number:"
  INPUT a
  PRINT "Second number:"
  INPUT b
  SET result TO a DIV b
  PRINT "Result:" + result
END

# Multiple Operations
START
  PRINT "Enter first number:"
  INPUT a
  PRINT "Second number:"
  INPUT b
  
  SET sum TO a + b  
  SET difference TO a - b  
  SET product TO a * b  
  SET division TO a / b  

  PRINT "Sum: " + sum  
  PRINT "Difference: " + difference  
  PRINT "Product: " + product  
  PRINT "Division: " + division  
END
